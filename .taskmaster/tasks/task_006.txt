# Task ID: 6
# Title: 실시간 음정 시각화 개발
# Status: pending
# Dependencies: 5, 14
# Priority: medium
# Description: Spring WebSocket + STOMP를 사용하여 사용자의 음성 입력을 실시간으로 분석하여 음정(pitch) 데이터를 추출하고, 이를 프론트엔드에 스트리밍하는 API를 개발합니다. 시각화 구현은 태스크 14에서 담당합니다.
# Details:
Spring Boot 서버에서 WebSocket + STOMP 프로토콜을 통해 음정 분석을 수행하고, 실시간으로 데이터를 스트리밍합니다. Java 기반 CREPE 라이브러리 또는 Python 프로세스 연동을 통해 YIN 알고리즘을 사용하여 음정을 추출합니다. @MessageMapping과 SimpMessagingTemplate을 활용한 양방향 통신을 구현합니다.

# Test Strategy:
Spring WebSocket 연결 안정성과 실시간 음정 분석의 정확도를 테스트합니다. STOMP 메시지 브로커를 통한 데이터 전송의 안정성과 API의 응답성을 보장합니다. 다중 사용자 동시 연결 테스트를 수행합니다.

# Subtasks:
## 1. Spring WebSocket + STOMP 설정 [pending]
### Dependencies: None
### Description: 프론트엔드로부터 실시간 오디오 스트림을 수신하기 위한 Spring WebSocket + STOMP 엔드포인트를 구성합니다.
### Details:

3. 클라이언트 연결 관리 및 세션 추적
4. CORS 설정 및 보안 인증 통합 (JWT)
5. 연결/해제 이벤트 핸들링 (@EventListener)

## 2. 실시간 음정 추출 서비스 구현 [pending]
### Dependencies: 6.1
### Description: Spring @Service를 사용하여 CREPE 또는 YIN 알고리즘으로 오디오 청크에서 음정을 추출하는 로직을 개발합니다.
### Details:
1. PitchAnalysisService 클래스 구현 (@Service)
2. Java 기반 오디오 처리 라이브러리 통합 (javax.sound.sampled)
3. Python CREPE/YIN 스크립트와의 ProcessBuilder 연동
4. 오디오 청크 단위 실시간 처리 (@Async)
5. 음정 추출 결과 캐싱 (Redis)

### Dependencies: 6.2

5. 에러 처리 및 연결 상태 관리
