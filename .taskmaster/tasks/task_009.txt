# Task ID: 9
# Title: 음역대 및 음색 기반 추천 개발
# Status: pending
# Dependencies: 8
# Priority: medium
# Description: Spring Data JPA + Redis를 사용하여 사용자의 음역대(F0 범위)와 음색 특징을 분석하고 개인화된 노래 추천 시스템을 구현합니다.
# Details:
Spring Boot 서버에서 사용자의 음성에서 F0(기본 주파수)를 추출하여 음역대를 계산하고, Python HuBERT 모델(superb/hubert-large-superb-sid)과 연동하여 1024차원 음색 특징 벡터를 생성합니다. SingerEmbeddingSystem과 UserEmbeddingExtractor를 활용하여 Supabase에 저장된 곡 데이터베이스와 코사인 유사도를 비교하고 사용자 음성 특성에 맞는 노래를 추천하는 시스템을 개발합니다. Redis를 통한 캐싱으로 성능을 최적화합니다.

# Test Strategy:
Spring Boot Test를 사용하여 추천 정확도 및 응답 성능을 테스트합니다. Redis 캐싱 효과와 Supabase 연동을 검증하고, HuBERT 모델 기반 추천 시스템의 개인화 수준을 평가합니다.

### Dependencies: None

5. 결과를 VocalRange 엔티티로 Supabase 저장

## 2. HuBERT 음색 분석 시스템 연동 [pending]
### Dependencies: 9.1
### Description: Spring @Async를 사용하여 Python HuBERT 모델(SingerEmbeddingSystem, UserEmbeddingExtractor)과 비동기 연동하고 1024차원 음색 특징 벡터를 추출합니다.
### Details:
1. TimbreAnalysisService 클래스 구현 (@Service, @Async)
2. ProcessBuilder를 통한 Python HuBERT 스크립트 연동 (superb/hubert-large-superb-sid)
3. UserEmbeddingExtractor를 사용한 1024차원 임베딩 추출
4. 10초 세그먼트 분할 및 평균 임베딩 계산 로직 구현
5. 음색 특징 벡터를 S3에 .npy 파일로 저장 (embeddings/{user_id}/)
6. CompletableFuture를 통한 비동기 처리 결과 반환
7. Redis를 통한 음색 벡터 메타데이터 캐싱
