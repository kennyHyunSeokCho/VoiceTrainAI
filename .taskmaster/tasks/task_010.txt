# Task ID: 10
# Title: 행동 로그 인사이트 시각화 생성
# Status: pending
# Dependencies: 9, 11, 14
# Priority: medium
# Description: Spring Boot + Spring Data JPA + Redis를 사용하여 사용자의 연습 기록을 분석하고 시각화에 필요한 데이터를 제공하는 API를 개발합니다. 이 태스크는 데이터 처리 및 제공에만 집중하고, 실제 UI 구현은 태스크 14에서 담당합니다.

Spring Boot 서버에서 사용자의 보컬 연습 활동을 자동으로 로깅하고, @Scheduled를 통해 시간에 따른 피치 정확도, 감정 표현력, 음역대 확장 등의 성장 지표를 분석합니다. 분석된 데이터를 Spring MVC API를 통해 제공하고, Redis 캐싱으로 성능을 최적화하여 다른 시스템에서 시각화를 위한 데이터를 활용할 수 있도록 합니다.

# Test Strategy:
Spring Boot Test를 사용하여 API의 데이터 처리 정확성과 응답 속도를 테스트합니다. 제공된 데이터가 시각화에 적합한지 확인하고, Redis 캐싱과 Supabase 연동 성능을 검증합니다.
